# 0.1.0a6 — 履歴タブと停止後の待ち時間の改善

大ウィンドウに「履歴」タブを追加しました。保存済みの音声入力を新しい順に読み返し、本文や認識原文をコピーできます。ログはローカルに保持し、スクロールに合わせて少しずつ読み込みます。ファイル全体を最初に読み込まないため、大きなログが録音開始を妨げない構成です。詳しくは[履歴の使い方](HISTORY.md)を参照してください。

録音中の字幕は維持し、停止時には処理中の古い字幕計算を中断して最終認識を優先するようにしました。確定済みの区間は保持し、未確定区間は最後の音声サンプルまで認識します。これから話す言葉を予測する処理や、新しいモデルは追加していません。

MacのCPUによる合成音声の比較では、約10秒の素材で停止後の認識待ちの中央値が1.21秒から0.61秒になりました。一方、約15秒の素材では0.27秒から0.30秒で、改善していません。各条件3回の結果で、Windows実機での速度や、句読点補完・転記までの時間を保証する数値ではありません。[計測条件](PERFORMANCE.md)も確認してください。

辞書・設定・保存済みログ・取得済みモデルは引き継ぎます。配布exeは引き続き未署名です。Windows実機での導入・更新・実マイク・入力先への転記は確認が必要です。

[ダウンロードと導入](INSTALL.md)・[ビルド方法](BUILD.md)・[動作報告](https://github.com/k3peta/shigaraki/issues/new/choose)

# 0.1.0a5 — 初期辞書を共通のAI用語へ整理

初期辞書から大学名などの個人用語を外し、OpenAI、ChatGPT、Codex、Antigravity、Claude、Geminiの6語を収録しました。「アンチグラビティ」からAntigravityへの表記補正などに加え、Haasの認識候補にも使います。候補を渡しても、必ず正しく認識されるとは限りません。

各自が登録した辞書を優先し、既存の辞書・設定・ログ・取得済みモデルは保持します。以前の組み込み大学名だけを使っていた場合は、必要な語を「単語辞書」に登録してください。未登録の大学名がモデル自身の認識結果に出ることはありますが、信楽からの優先候補や自動置換には使わなくなります。

認識エンジン、モデル、録音・転記の操作はa4と同じです。配布exeは引き続き未署名で、Windows実機でのa5の導入・更新・音声入力は確認が必要です。

[ダウンロードと導入](INSTALL.md)・[ビルド方法](BUILD.md)・[動作報告](https://github.com/k3peta/shigaraki/issues/new/choose)

# 0.1.0a4 — Haas版を「信楽」として本流へ

アプリ名、起動用exe、スタートメニュー、Windowsのアプリ一覧を「信楽」に統一しました。Haasを使うこの版を、今後の信楽Windows版の本流とします。

Haasテスト版からはそのまま更新でき、辞書・設定・ログ・取得済みモデルを引き継ぎます。内部の保存先は互換性のため維持しています。旧方式版のアプリやデータは変更しません。同時には起動できません。

旧Haas名のショートカットを更新し、別アプリを指す既存の同名ショートカットは保持します。デスクトップに作成できなかった場合は、スタートメニューの「信楽」フォルダー内から起動できます。

音声認識モデルとストリーミング制御はa3と同じです。今回の変更は名称と更新・導入案内の整備です。配布exeにはまだコード署名がありません。SmartScreenとSmart App Controlの違い、利用者が確認した暫定手順と適用条件を[導入ガイド](INSTALL.md#windows-security)へ追記しました。Windows実機でのa4の導入・更新・削除は、引き続き確認が必要です。
