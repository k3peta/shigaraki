# 履歴を見る

大ウィンドウの「履歴」タブで、保存済みの音声入力を新しい順に確認できます。日時、入力先アプリ、貼り付け結果、本文の先頭を一覧に表示します。

大ウィンドウで停止し、まだ貼り付けていない記録は「転記前の文章」と表示します。これは入力先へ転記した記録ではありません。

記録を選ぶと、「入力した本文」と「認識した原文」を切り替えて読めます。「本文をコピー」「原文をコピー」で、選んだ記録をコピーできます。この操作で外部アプリへ自動入力することはありません。

下へスクロールするか「さらに読み込む」を押すと、古い記録を最大40件ずつ追加で読み込みます。ファイル全体を最初から読み込まず、1回の読み込みは最大512KiBです。画面の一覧は最大200件に保ち、それより古い記録を読み込むと、先に表示していた新しい記録を一覧から外します。ログファイルから記録を削除することはありません。新しい記録へ戻る場合は「最新に更新」を押してください。

履歴表示中に保存された新しい記録も、「最新に更新」で読み込めます。録音や転記など音声入力の処理中は、履歴の追加読み込みとコピーを一時停止します。

ログがない場合は空の画面になります。「設定」の「認識結果と入力先アプリを、このPCに保存する」がオンなら、次の入力から保存されます。設定をオフにしても、それまでに保存したログは削除されません。

読み取れない行は見送り、件数を案内します。1行が256KiBを超える記録も画面表示の対象外ですが、ファイルは変更しません。ログが削除・置換・短縮された場合や、選んだ記録の内容が変わった場合は、読み込みまたは本文の表示を止めて更新を案内します。

ログには認識した文章が含まれます。「保存場所を開く」で、このPC内の `recognition.jsonl` を確認できます。履歴の表示やコピーでは、ログを外部へ送信しません。
