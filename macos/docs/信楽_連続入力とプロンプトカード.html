連続入力とプロンプトカード

1回で録音・停止、2回で確定して転記する

入力欄を選んで左Controlを素早く2回押すと、大ウィンドウを開けます。録音中は小窓を出さず、この画面に途中の文字を表示します。

  1. 入力先のアプリの入力欄にカーソルを置き、左Controlを素早く2回押します。
  2. 左Controlを単独で1回押して離すと、少し待って録音が始まります。その後はキーを押し続けずに話せます。
  3. もう一度1回押して離すと停止し、本文を大ウィンドウに残します。ここでは転記しません。再度1回押すと、改行して続きを録音できます。
  4. 入力を終えるときは左Controlを素早く2回押します。最後の認識処理が終わると大ウィンドウを閉じ、入力先へ一度だけ転記します。録音中や確定待ち中も、この操作を使えます。

録音アイコンでも開始・停止できます。停止だけでは転記せず、認識した本文を残します。左上の赤いボタンや⌘Wも転記せずに閉じます。録音中に閉じた場合は録音を中止し、それまでの本文を残します。

録音は小窓・大ウィンドウとも1回5分までです。上限では自動転記せず、認識できた本文を残します。次の録音で続きを追記できます。大ウィンドウを閉じている間は、選択したキーを押している間だけ録音し、離すと確定して転記します。

「操作に使うキー」は左Control、左Option、なしから選べます。小窓では長押し、大ウィンドウでは1回押しの録音・停止と2回押しの確定に使います。「大ウィンドウを呼び出すキー」では、閉じた大ウィンドウを開く2回押しのキーを選べます。別のキーを選んだ場合も、大ウィンドウ内ではそのキーの2回押しで確定・転記できます。

「設定」→「連続入力の開始・停止」では、従来のControl＋Shiftなどの組み合わせも選べます。修飾キーだけの組み合わせは、すべてのキーを離した時点で切り替わります。文字キーも一緒に押した場合は切り替わりません。

大ウィンドウでは、2回押しによる確定時に、入力先のアプリの入力欄を確認してから転記します。入力欄・カーソル・既存の文章が変わった場合や、別のアプリを操作した場合は自動転記を中止し、認識した文章を残します。

大ウィンドウが閉じているときは、モデルの準備・確定・転記中でも呼び出しキーを2回押して、処理の状態を確認できます。小窓でキーを押し続けて録音している間は、この2回操作を無視します。

独自のプロンプトをカードに保存する

  1. 大きなウィンドウの「カード」を開きます。標準のメール・チャット・文書カードを編集するか、「新規」や「複製」でカードを作ります。
  2. カード名、用途、加工の指示を入力します。指示は1200文字までで、変更はMac内に自動保存されます。標準カードは「標準に戻す」で元の内容に戻せます。
  3. 「音声入力」の「共通の加工カード」で使用するカードを選びます。「用途に合う標準カード」を選ぶと、用途に応じた標準カードが使われます。
  4. 録音を停止し、「用途に合わせて整える」で結果を試します。自動で加工したい場合は、「設定」の「停止後に用途に合わせて整形する」をオンにします。

指示の例：「句点の直後で改行してください。一行には一文だけを書き、空行は入れないでください。」文体・段落・句読点・箇条書きなどの調整に使えます。要約・翻訳・新しい事実の追加は行わず、数値や否定などの変化を検出した場合は原文を残します。なお、内容が完全に同じであることを保証する検査ではありません。

標準カードの書式と例文

メール、チャット、文書の標準カードは、用途・整形の指示・入力例・出力例を同じ書式でそろえています。メールは丁寧な「です・ます調」、チャットは話し手の口調、文書は本文の主な文体を使います。どの用途でも、話した内容や数値、否定、依頼や約束の強さを保ち、本文にない情報は追加しません。

「カード」で指示と例文を編集できます。指示は1200文字まで、入力例と出力例は各300文字までです。例文は両方を入力したときだけ、文体と書式の参考として使われます。例文の語句や数値を今回の本文に追加するための機能ではありません。

カスタムカードは、指示だけでも使えます。例文が片方だけの場合は例文を使わず、指示が空の場合は用途に合う標準の指示を使います。「複製」では例文もコピーされ、標準カードの「標準に戻す」では指示と例文をまとめて初期状態に戻します。

更新時は、未編集の旧標準カードだけを新しい内容に更新します。編集済みの標準カードとカスタムカードは、そのまま残します。編集済みの標準カードにも新しい内容を使いたい場合は、先に「複製」で自分の設定を残し、元のカードを「標準に戻す」で更新してください。

アプリごとに加工カードを選ぶ

「アプリ別」でアプリを追加し、「加工カード」を選びます。「共通のカード設定」を選ぶと共通設定を引き継ぎ、「用途に合う標準カード」を選ぶとそのアプリの用途に合うカードを使います。特定のカードを選んだ場合は、そのカードの用途と指示を使います。「原文」と「整形しない」は、カードの設定より優先されます。アプリごとの用途・整形方法・使う情報も変更できます。

転記の再試行とテキストログ

「最後の入力をコピー」は、大ウィンドウのどのタブでも下部に表示します。最後に確定・中止した認識結果を取り出せます。

自動転記に失敗したときや、転記結果を確認できない場合は、警告を表示し、自動では再送しません。大ウィンドウを開いている間は、この画面で警告を確認できます。小窓で入力していた場合は、小窓が8秒後に閉じます。認識した文章は、起動中の「最後の入力」として保持します。全文を確認するには、左Controlを素早く2回押すか、小窓の歯車ボタン、またはメニューバーの「設定・辞書・全文を開く」から大きいウィンドウを開いてください。まず入力欄を確認し、文字が入っていない場合だけ、貼り付け先にカーソルを置いてControl＋Option＋Vを押すと、最後の入力を貼り付け直せます。大きいウィンドウの「最後の入力を貼り付け」ボタンを押すと、直前のアプリの入力欄へ貼り付けます。

「設定」→「認識した文字をテキストログに保存」で、ログの保存を切り替えます。「ログを開く」から、保存したテキストを確認できます。保存先はホームフォルダ内の Library/Application Support/信楽/音声入力ログ.txt です。確定時に認識した文字を追記し、加工後の文字が異なる場合は両方を残します。途中で中止した場合も、認識できたところまでを保存します。録音データや入力欄の前後の文章はログに含めません。ログの整理・アーカイブは手動で行ってください。保存できない場合は画面で知らせます。

端末内の加工と待ち時間

カードを使う加工にはApple Intelligenceの端末内モデルを使います。外部APIに音声・文章・カードを送信しません。端末内モデルが使えない場合は原文を残します。自動整形では最大4秒、手動整形では最大15秒を目安に待ちます。1回の整形は1800文字までで、それを超える長い文章は原文を残します。なお、これは音声入力自体の文字数制限ではありません。

基本操作のマニュアル / 文章整形・アプリ別設定の案内

認識途中の文字は、ログ保存がオンの場合、約3秒ごとに同じフォルダの「最後の認識.txt」へ更新されます。確定や中止のときにも更新されます。アプリが突然終了した場合は、このファイルから直近までの文字を取り出せます。最後の保存後に認識した文字は残らない場合があります。「設定」の「保存先」からフォルダを開けます。

ログには、入力開始・記録の日時、タイムゾーン、入力先アプリの名前と識別子、取得できたサイトのドメイン、文章の用途、指定したカード、転記結果をあわせて記録します。ウィンドウ名は、文章整形のコンテクスト設定でウィンドウ情報を使う場合に記録します。サイトを取得できない場合は推測せず、アプリ名を残します。URLのパス、検索パラメータ、入力欄の前後の文章は保存しません。転記の確認は入力欄への反映の確認であり、投稿や保存の完了を表すものではありません。

読みやすい「音声入力ログ.txt」に加え、同じフォルダの「音声入力ログ.jsonl」に機械処理用の記録を追記します。JSONLには、認識した文字、加工後の文字、日時、入力先、転記結果などを1行ごとに保存します。この版以降の入力が対象です。再貼り付けの記録は、元の入力IDと関連付けて保存するため、後日の集計では再試行を別の音声入力として数えずに扱えます。日付や入力先ごとの集計、一日のまとめの作成、Obsidianへの転記につなげるための記録です。

ログ保存がオンの場合、通常の音声入力の最後の本文・原文・未転記の状態を「最後の入力.json」に保存し、次の起動時に復元します。外部文書や音声編集の本文全体は、この復旧ファイルには保存しません。

ログ保存をオフにすると新たなログや復旧ファイルは保存せず、文章は起動中のメモリだけに保持します。既存のログや復旧ファイルは自動削除しないため、必要に応じて手動で整理してください。
