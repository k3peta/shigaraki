音声編集（旧版の参考資料）

v0.5.1では、音声編集のボタン・設定キー・ショートカットを通常操作から外しています。本文の手直しや文章の整形、カードは引き続き使えます。以下は旧版の参考資料です。現在の操作は「操作マニュアル」で確認してください。
操作マニュアルを開く

旧版の説明を表示 信楽 v0.4.14 / 2026年10月6日

メインパネルで編集し、確認してから貼り付ける

音声編集はメインパネルで行います。編集モードでは自動転記を停止し、結果を確認してからコピーするか、「確認して貼り付け」を押します。通常の音声入力の自動転記設定は変更しません。

最後の入力を原文からやり直す

  1. メインパネル、またはメニューバーの「最後の入力を再編集」を選びます。
  2. 転記前の原文が呼び戻され、編集モードに切り替わります。本文を直接手直しすることも、加工カードと用途を選んで「用途に合わせて整える」を使うこともできます。
  3. 必要なら本文の一部を選択し、Control＋Option＋Eを押し続けながら編集を指示します。選択していない場合は本文全体を対象にします。キーを離すと、編集結果が本文に表示されます。
  4. 内容を確認します。すでに入力先へ転記している場合は、そのアプリで置き換える文章を選択してから、「確認して貼り付け」またはControl＋Option＋Vを使います。コピーして、手動で貼り付けることもできます。

「原文へ戻す」は信楽側の本文だけを復元します。入力先の文書を自動で元に戻したり、その後の手直しを取り消したりはしません。原文に戻すと、信楽内で加えた編集も元に戻ります。「通常入力に戻る」で編集モードを終了します。メインパネルを閉じても、起動中は編集内容を保持します。通常の音声入力を始めると、表示は新しい入力に切り替わります。

外部アプリの文章を読み込む

入力先でControl＋Option＋Eを押し続けながら指示を話します。選択している場合はその範囲、選択していない場合は入力欄の全文を読み込み、メインパネルを開きます。結果は信楽に表示し、入力先は変更しません。

メインパネルに読み込んだ後も、本文の一部を選択すればその範囲だけを、選択を解除すれば本文全体を編集できます。音声指示は本文とは別に表示します。編集モードの録音アイコンから指示を話す場合は、話し終えたら赤い停止アイコンを押します。

「確認して貼り付け」では、読み込み元の本文と対象範囲が一致する場合だけ転記します。入力先を変更した場合や、すでに結果を転記している場合は、元の範囲を選び直すかコピーを使ってください。確認できない入力欄には自動で上書きしません。

使える指示

  • 「東京を大阪に置き換えて」：対象の文章に含まれる「東京」を、すべて「大阪」に置き換えます。「変換して」「変更して」「変えて」「直して」も使えます。
  • 「信楽に置き換えて」：対象の文章全体を「信楽」に置き換えます。選択がない場合は本文全体が短い一語に置き換わるため、結果を確認してください。
  • 「敬語にして」「丁寧にして」「常体にして」「箇条書きにして」「句読点を整えて」「改行を整えて」：Apple Intelligenceの端末内モデルで文章を整えます。

「設定」→「音声編集のキー」で、Control＋Option＋E、Option＋Shift＋E、「使わない」を選べます。語句の置換はモデルを使わず、認識した指示の文字列をそのまま使います。似た読みの別の漢字を推測したり、誤認識された語句を自動で補ったりはしません。指定した語句が見つからない場合や、対応していない指示の場合は変更しません。

対象範囲と長文

外部アプリの「文書全体」は、カーソルがある入力欄から取得できる本文です。アプリが本文を提供しない場合は読み込めません。ターミナルでは使えません。語句の置換は10万文字まで、置換後の文章は20万文字までです。文体変更は1,800文字までで、最大15秒を目安に待ちます。長い文書の文体を変更する場合は、必要な範囲だけ選択してください。編集待ちの間に信楽側の本文が変わった場合も、結果は反映しません。

端末内での処理とログ

音声認識、語句の置換、文体変更はMac内で処理します。外部APIへ音声や文書を送りません。語句の置換はApple Intelligenceが利用できない場合も使えます。文体変更では、数値や否定などの変化を検出した場合は反映を中止します。内容が完全に同じであることを保証する検査ではありません。

ログ保存がオンの場合、音声指示、日時、入力先、対象範囲、変更後の文字数を記録します。編集時の記録は未転記として残し、明示的な貼り付けの結果は別に記録します。読み込んだ文書や編集後の文書全文はログへ保存しません。編集中の本文は起動中に保持しますが、アプリを終了すると失われます。必要な文章はコピーして保存してください。通常の音声入力の文字ログは、これまでどおり設定に従って保存します。
