# 信楽（しがらき）

v0.5.0（build 23）/ 2026年11月2日

[Mac版DMGのダウンロード](https://github.com/k3peta/shigaraki/releases/tag/macos-v0.5.0) / [ビルド方法](../docs/BUILD_MACOS.md) / [クレジット](../CREDITS.md)

話している途中から字幕を表示する、Mac用のローカル音声入力アプリです。日本語向けのHaas-ja-v1.0 Q4_Kモデルで短い音声を繰り返し認識する、擬似ストリーミング方式です。認識した字幕は後から修正されることがあります。

[操作マニュアル](docs/信楽_操作マニュアル.md) / [操作早見表](docs/信楽_操作早見表.md) / [導入ガイド](docs/信楽_導入ガイド.md) / [更新履歴](docs/RELEASE_NOTES.md)

macOS 26以降のApple Silicon Macに対応し、CPUで認識します。初回はアプリ内で約352MBのモデルを自動取得・検証し、準備完了後に使い始められます。DMG内の「信楽.app」をApplicationsへコピーして開いてください。別のインストーラーは必要ありません。

## 確認状況と制約

この版はプレリリースです。モデルを使わない自動テスト、ファイル音声での途中字幕と確定、モデルの取得・検証・読み込み・再利用を確認しています。実マイクでの収音、実際のキー操作、他アプリへの実転記は未確認です。すべての入力欄での動作や、遅延の上限を保証するものではありません。

音声認識は日本語向けで、1回の録音は5分までです。文章整形はApple Intelligenceを使う任意の別機能で、自動整形は初期状態ではオフです。

## 押して話し、離すと入力

大ウィンドウを閉じている間は、左Controlを押している間だけ録音します。途中の文字は小窓で確認できます。Haasのモデルが短い音声を繰り返し認識するため、字幕は後から修正されることがあります。

### 入力の3ステップ

1. 入力したいアプリの入力欄にカーソルを置きます。
2. 左Controlを単独で長押しし、そのまま話します。
3. 話し終わったらキーを離します。認識結果を確定し、入力欄へ一度だけ貼り付けます。

### 波形と小窓のボタン

波形が動くと、マイクが音を拾っています。右上にはコピー、歯車、録音・停止、閉じるボタンがあります。

小窓の×は表示を隠すボタンです。録音を終えるにはキーを離します。転記できると小窓が閉じます。メッセージの送信は行いません。

## 1回押して録音・停止、2回で確定

入力欄を選んで左Controlを素早く2回押すと、大ウィンドウを開けます。録音中は小窓を出さず、この画面に途中の文字を表示します。

### 長い文章を入力する

1. 入力先のアプリの入力欄にカーソルを置き、左Controlを素早く2回押します。
2. 左Controlを単独で1回押して離すと、少し待って録音が始まります。その後はキーを押し続けずに話せます。
3. もう一度1回押して離すと停止し、本文を大ウィンドウに残します。ここでは転記しません。再度1回押すと、改行して続きを録音できます。
4. 入力を終えるときは左Controlを素早く2回押します。最後の認識処理が終わると大ウィンドウを閉じ、入力先へ一度だけ転記します。録音中や確定待ち中も、この操作を使えます。

### 録音アイコンと待ち時間

録音アイコンでも開始・停止できます。停止だけでは転記せず、認識した本文を残します。

録音開始は2回押しとの区別のため、キーを離してから約0.35秒待ちます。録音中の1回押しによる停止では、この待ちはありません。

## キーを選ぶ・画面を閉じる

タブの順番は、音声入力、設定、単語辞書、アプリ別、カードです。大ウィンドウはタイトルバーをつかんで移動できます。

### 開く・閉じる

大ウィンドウが閉じているときは、左Controlを素早く2回押すと開きます。確定・転記・準備の途中でも、状態の確認に使えます。小窓でキーを押し続けて録音している間は無視します。

大ウィンドウが開いているときの2回押しは、本文を確定して閉じ、転記する操作です。左上の赤いボタンや⌘Wは、転記せずに閉じて本文を残します。録音中なら録音を中止します。閉じてもアプリはメニューバーに残ります。

### キーと自動起動

「操作に使うキー」は左Control、左Option、なしから選べます。小窓では長押し、大ウィンドウでは1回押しの録音・停止と2回押しの確定に使います。「大ウィンドウを呼び出すキー」では、閉じた大ウィンドウを開く2回押しのキーを選べます。別のキーを選んだ場合も、大ウィンドウ内ではそのキーの2回押しで確定・転記できます。

「ログイン時に信楽を起動」をオンにすると、次回ログイン時からメニューバーに常駐します。

## 文字が入らないときも取り出せる

「最後の入力をコピー」は、大ウィンドウのどのタブでも下部に表示します。最後に確定・中止した認識結果を取り出せます。

### 転記できなかったとき

まず入力先の文字を確認します。転記を確認できなくても、実際には入っている場合があります。信楽はこの状態で自動再送しません。入っていない場合だけ、「最後の入力を貼り付け」かControl＋Option＋Vで再試行します。

「本文をコピー」は表示中の本文、「最後の入力をコピー」は最後の認識結果をコピーします。コピー後は入力先に戻り、⌘Vで貼り付けます。

大ウィンドウでは、2回押しによる確定時に、入力先のアプリの入力欄を確認してから転記します。入力欄・カーソル・既存の文章が変わった場合や、別のアプリを操作した場合は自動転記を中止し、認識した文章を残します。

### 認識した文字をログに残す

「設定」の「認識した文字をテキストログに保存」で保存を切り替えます。初期設定はオンです。「ログを開く」や「保存先」から記録を確認できます。

保存先はホームフォルダ内のLibrary/Application Support/信楽です。音声入力ログ.txtと音声入力ログ.jsonlに、日時、入力先アプリ、取得できたサイトのドメイン、用途、カード、転記結果、認識・整形後の文字を保存します。

録音データ、URLのパスや検索パラメータ、入力欄の前後の文章はログに保存しません。ログの整理やアーカイブは手動で行います。

ログ保存がオンの場合、通常の音声入力の最後の本文・原文・未転記の状態を「最後の入力.json」に保存し、次の起動時に復元します。外部文書や音声編集の本文全体は、この復旧ファイルには保存しません。

ログ保存をオフにすると新たなログや復旧ファイルは保存せず、文章は起動中のメモリだけに保持します。既存のログや復旧ファイルは自動削除しないため、必要に応じて手動で整理してください。

## 入力先・許可・待ち時間を確認する

字幕が出たことと、入力欄への転記を確認できたことは別です。転記後は、入力先に文章が入ったか確認してください。

### 字幕は出るのに転記されない

「設定」の「小窓で停止したら入力欄へ転記」をオンにし、「直接入力の許可あり」を確認します。大ウィンドウでは、1回押しの停止後は本文を残し、2回押しで確定したときに転記します。「許可を確認」からmacOSのアクセシビリティを許可できます。初回はマイクの許可も必要です。

パスワード欄や入力欄以外には貼り付けません。対応しないアプリや入力欄では、コピーして使ってください。録音中のキー入力や外部へのクリックは、入力先の変更として扱います。

### 停止後に少し待つことがある

最後の認識結果を確定してから転記します。自動整形がオンなら、さらに整形を待ちます。初回の音声モデル準備、Macの負荷、入力先のアプリによって時間は変わります。

小窓・大ウィンドウとも、1回の録音は5分までです。上限では自動転記せず、認識できた本文を残します。大ウィンドウで内容を確認し、次の録音で続きを追記できます。

### 端末内で処理する

音声認識にはHaas-ja-v1.0のQ4_K量子化モデルを使い、CPUで処理します。AppleのSpeechAnalyzer／SpeechTranscriberは使いません。文章整形は任意の別機能で、Apple Intelligenceの端末内モデルを使います。外部のフロンティアモデルへ音声・文章・カードを送る機能はありません。

macOS 26以降のApple Silicon Macが対象で、音声認識は日本語向けです。初回はHaasのモデル（約352MB）を自動で取得し、サイズとSHA-256を検証してから読み込みます。起動中はモデルを保持し、入力のたびに読み込み直す待ち時間を減らします。

詳しい説明はアプリのヘルプから開けます。以下のHTMLガイドをダウンロードし、ブラウザーで開いて読むこともできます。

[文章整形・アプリ別設定](docs/信楽_文章整形とアプリ別設定.html) / [連続入力・カード・ログ](docs/信楽_連続入力とプロンプトカード.html) / [音声編集](docs/信楽_音声編集.html)

文章整形は任意の別機能で、Apple Intelligenceの端末内モデルを利用します。自動整形は初期状態ではオフです。音声認識だけならApple Intelligenceは不要です。

旧版の設定と単語辞書は引き継ぎますが、Haasモデルの初回準備は別途必要です。旧版を終了してから更新し、同時に起動しないでください。別の場所にある旧版は自動で削除しません。

この試用版は開発用署名付きで、Appleの公証は未実施です。起動を止められた場合は、導入ガイドの条件とApple公式の案内を確認してください。

## モデルと推論エンジンの出典

日本語認識には、Third Intelligenceの[Haas-ja-v1.0](https://huggingface.co/third-intelligence/Haas-ja-v1.0)を使っています。GGUF変換・Q4_K量子化版はSakasegawaの[Haas-ja-v1.0-GGUF](https://huggingface.co/sakasegawa/Haas-ja-v1.0-GGUF)、CPU推論は同氏の[speech.cpp 0.10.0](https://github.com/nyosegawa/speech.cpp/tree/06590811a90041f935a470ba0e2b85346d2fc041)を使用します。モデルの学習・量子化は信楽では行っていません。

信楽は録音操作、大小ウィンドウ、録音中の字幕更新、辞書・文脈との接続、入力先への転記と復旧を追加しています。上流の作者・ライセンスはそれぞれ維持し、配布物にも著作権表示とライセンス原文を同梱します。
